\VerdierSemanticAnchor{ch2-2-1-5-criterion}
Let $\mathcal D'$ be a full subcategory of $\mathcal D$ stable under
translations. In order that $\mathcal D'$ admit a triangulated structure
making $\mathcal D'$ a full triangulated subcategory of $\mathcal D$, it is
necessary and sufficient that, for every pair $X,Y$ of objects of
$\mathcal D'$ and every morphism $f\colon X\to Y$, there exist a distinguished
triangle in $\mathcal D$, $(X,Y,Z,f,g,h)$, where $Z$ is an object of
$\mathcal D'$.

\VerdierSemanticAnchor{ch2-2-1-6}
\medskip
\noindent\textbf{2.1.6.}\quad
\VerdierSemanticAnchor{ch2-2-1-6-saturated}
Let $\mathcal D$ be a triangulated category. A full triangulated subcategory
$\mathcal D'$ of $\mathcal D$ is said to be \emph{saturated} if it has the
following property:

\VerdierSemanticAnchor{ch2-2-1-6-direct-summand}
\par\smallskip
\noindent\makebox[0pt][l]{(2.1.6.1)}%
\begin{minipage}[t]{\linewidth}
  \centering\itshape
  Every direct summand in $\mathcal D$ of an object of $\mathcal D'$\\[-1pt]
  is isomorphic to an object of $\mathcal D'$.
\end{minipage}
\par\smallskip

\VerdierSemanticAnchor{ch2-2-1-6-direct-summand-definition}
\noindent (A direct summand of an object $Y$ is an object $X$ such that there
exist an object $Z$ and an isomorphism $X\oplus Z\xrightarrow{\sim}Y$).

\VerdierSemanticAnchor{ch2-2-1-7}
\medskip
\noindent\textbf{2.1.7.}\quad
\VerdierSemanticAnchor{ch2-2-1-7-denominator-set}
Let $\mathcal D'$ be a full triangulated subcategory of a triangulated
category $\mathcal D$. Denote by $S(\mathcal D')$ the set of morphisms of
$\mathcal D$ defined as follows:

\VerdierSemanticAnchor{ch2-2-1-7-characterization}
\par\smallskip
\noindent\makebox[0pt][l]{(2.1.7.1)}%
\begin{minipage}[t]{\linewidth}
  \centering\itshape
  A morphism $f\colon X\to Y$ belongs to $S(\mathcal D')$ if and only if there exists\\[-1pt]
  a distinguished triangle in $\mathcal D$, $(X,Y,Z,f,g,h)$, where $Z$ is an object of $\mathcal D'$.
\end{minipage}
\par\smallskip

\VerdierSemanticAnchor{ch2-2-1-8}
\medskip
\noindent\textbf{Proposition 2.1.8.}\quad
\VerdierSemanticAnchor{ch2-2-1-8-proposition}
\emph{The set $S(\mathcal D')$ (2.1.7.1) is a multiplicative system (2.1.4)
of $\mathcal D$. It is saturated if and only if the subcategory
$\mathcal D'$ is saturated.}

\VerdierSemanticAnchor{ch2-2-1-8-proof-plan}
To prove the first assertion, it suffices, by virtue of (2.1.3), to show that
the set $S(\mathcal D')$ has properties SM1), SM3), SM5), and SM6). We shall
show successively that $S(\mathcal D')$ has these properties, and then prove
the last assertion.

\VerdierSemanticAnchor{ch2-2-1-9}
\medskip
\noindent\textbf{2.1.9.}\quad
\VerdierSemanticAnchor{ch2-2-1-9-sm1}
\emph{The set $S(\mathcal D')$ has property SM1).}

\VerdierSemanticAnchor{ch2-2-1-9-identity}
First, it is clear that for every object $X$ of $\mathcal D$, the morphism
$\operatorname{id}_X$ is an element of $S(\mathcal D')$. This follows
immediately from TRI) and from the fact that the zero objects of $\mathcal D'$
are zero objects of $\mathcal D$.

\VerdierSemanticAnchor{ch2-2-1-9-composition}
The fact that $S(\mathcal D')$ is stable under composition follows immediately
from axiom TRIV) and (1.2.4). We leave the verifications to the reader.
